# Your package list: tools every machine of yours gets.
#
# One logical name per line: the binary `command -v` looks for (rg, not
# ripgrep). dj maps it to each package manager's package name through
# packages/renames/<manager>.txt, and to a fallback installer in
# packages/scripts/<name>.sh where no package manager ships it. Your own
# mappings and installers go beside this file, in renames/ and scripts/.
#
# Add to types/<type>.txt for one kind of machine, hosts/<host>.txt for
# one machine. git, gpg, sops, age and just are dj's own requirements and
# are always installed, so they don't belong here.
#
# For example:
# rg
# fzf
# jq
